# DiagramBridge v0.3.20

## Deutsch

DiagramBridge ist eine Windows-x64-Anwendung zur lokalen Konvertierung von draw.io-/diagrams.net-Dateien (`.drawio` und `.xml`) in native Microsoft-Visio-Dateien (`.vsdx`) und/oder PDF-Dateien.

### Änderungen in 0.3.20

- Startfenstergröße auf **1300 × 840** angepasst; das Fenster bleibt normal größenveränderbar.
- Die leere Warteschlangenfläche verwendet jetzt dieselbe dunkle Oberfläche wie das Warteschlangenpanel.

### Funktionen

- Mehrere Quelldateien per Dateiauswahl oder Drag-and-drop in eine Konvertierungswarteschlange aufnehmen.
- Ausgaben als **Visio**, **PDF** oder **Visio + PDF** erstellen.
- Native Visio-Objekte statt einer gerasterten Ersatzansicht exportieren.
- Ausgabenamen und Zielordner festlegen.
- Vorhandene Ausgabedateien standardmäßig vor unbeabsichtigtem Überschreiben schützen.
- Integriertes visuelles Handbuch und Benutzeroberfläche auf Deutsch und Englisch.
- Sprache beim ersten Start anhand der Windows-Anzeigesprache wählen; manuelle DE/EN-Auswahl wird gespeichert.
- Lokale Verarbeitung auf dem Windows-Rechner.

### Hinweise

- Unterstützt Windows x64.
- Die lokale Export-Engine wird beim ersten Einrichten benötigt; hierfür ist eine Internetverbindung erforderlich.
- Die vollständigen Lizenz- und Drittanbieterhinweise befinden sich im Programmarchiv unter `ThirdPartyNotices`.
- Das veröffentlichte Release-Archiv enthält die ausführbare Anwendung und die erforderlichen Laufzeit-/Lizenzhinweise, nicht den Projekt-Source-Code.

## English

DiagramBridge is a Windows x64 application for locally converting draw.io/diagrams.net files (`.drawio` and `.xml`) into native Microsoft Visio files (`.vsdx`) and/or PDF files.

### Changes in 0.3.20

- Adjusted the initial window size to **1300 × 840** while retaining normal window resizing.
- Updated the empty queue viewport to use the same dark surface as the queue panel.

### Features

- Add multiple source files to a conversion queue using the file picker or drag and drop.
- Create **Visio**, **PDF**, or **Visio + PDF** output.
- Export native Visio objects rather than a rasterized replacement image.
- Configure output names and destination folders.
- Protect existing output files from accidental overwrite by default.
- Integrated visual guide and user interface in German and English.
- Select the initial language from the Windows display language; remember the manual DE/EN selection.
- Process diagram content locally on the Windows computer.

### Notes

- Windows x64 is required.
- The local export engine must be initialized on first use; an internet connection is required for this initial setup.
- Full license and third-party notices are included in the application archive under `ThirdPartyNotices`.
- The release archive contains the executable application and required runtime/license notices, not the project source code.
